# Theaterverein Bühnenfreunde Hemeln e.V.

Dies ist das offizielle Projekt-Repository der Website des Theatervereins Bühnenfreunde Hemeln e.V.

## Überblick

Diese Website dient der Präsentation des Vereins, seiner Aktivitäten, Kontaktdaten und rechtlichen Informationen. Das Projekt besteht aus statischen HTML-, CSS- und JavaScript-Dateien und wird über GitHub Pages veröffentlicht.

## Ziele

- Darstellung des Vereins und seiner Veranstaltungen
- Bereitstellung von Kontakt- und Impressumsinformationen
- Veröffentlichung rechtlicher Hinweise (Datenschutz, Haftungsausschluss)
- einfache, wartungsarme und schnelle Website ohne Backend

## Struktur

```text
.
├── index.html
├── kontakt.html
├── impressum.html
├── rechtliches.html
├── styles.css
├── sidebar.js
├── LICENSE
├── README.md
└── images/                 # Bilder
```

## Lokale Vorschau

Um die Website lokal anzusehen, kannst du die Dateien in einem Browser öffnen.
